# pto-service.com

Статическая версия страницы «Пластины для теплообменников».

Источник: https://www.pto-service.com/services/plastiny-teploobmennikov/

Открывайте `index.html` или опубликованный сайт GitHub Pages. Все изображения,
шрифты, стили и скрипты находятся в репозитории.

Каталог содержит 321 позицию, фильтры, сортировку, выбор количества и локальную
корзину. Первоначально видны 20 товаров; кнопка добавляет ещё четыре.

Формы подбора и консультации открывают подготовленное письмо в почтовом клиенте.
Серверная отправка заявок, оплата и вход в аккаунт не входят в статическую версию.
